# Final Project

Design and build an app of your own choosing, alone or in a group of up to
three. The topic is wide open — pick something you care about. What's fixed
is that the app has to put the course's core topics to work, so that the
project shows what you've learned.

The final project is worth **20%** of your course grade.

## Required topics

Every project must include all of these. The app is yours; these are how
we see the course in it.

- **Data model** with related collections
- **REST API** endpoints
- **Authentication**, and **at least two roles** enforced by authorization
- **Validation and error handling**
- **Tests** at more than one level
- A **real-time** feature
- A **client** that talks to your back end
- **Deployment** with HTTPS

Have an idea that's ambitious in some other way, and one of these doesn't
fit? Ask us. We're willing to relax a specific requirement for a good
reason — but ask before you build around it.

## Your repo

Your group works in one repo, created through Classroom50. The starter is
minimal — you build the app yourself — and includes a `docs/` folder for
the planning documents the milestones ask for. The README is for running
and using the app; `docs/` is for the plan and the architecture. Details in
[Your repo](./repo.md).

## Working in a group

Group size doesn't change the requirements. Working alone means more to
build; working in a group means coordinating. That's the trade-off.

- **Everyone owns the whole project.** At the final assessment, every member
  must be able to explain every required topic — not just the parts they
  built.
- **Use pull requests with review.** Changes reach `main` through a pull
  request that a teammate has reviewed. See
  [Working as a team](./team-workflow.md).
- **We look at contributions.** We'll look at commit, pull request and
  review history for roughly even contributions. If you pair-program, add a
  `Co-authored-by:` line so both people get credit.

## How we'll look at it

We'll post how each milestone is graded before it's due.

Across all of them, we'll look for each required topic in your app, using
`docs/topic-map.md` to find it, and ask whether it's done the way we've
practiced in class.

Your project is also part of the final-week in-person assessment: we'll ask
each of you to walk us through parts of it and explain how they work.
